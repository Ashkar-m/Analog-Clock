# Analog Clock

A simple analog clock built using Python's Tkinter library. The clock displays real-time hours, minutes, and seconds with animated hands.

## Features
- Displays an analog clock with real-time updates
- Uses trigonometric calculations for accurate hand movements
- Aesthetic UI with labeled hour markers

## Technologies Used
- Python
- Tkinter (for GUI)
- Math (for angle calculations)
- Time (for fetching current time)

## Getting Started

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Ashkar-m/Analog-Clock.git
   cd Analog-Clock
   ```
2. Run the script:
   ```bash
   python analog_clock.py
   ```


## How It Works
- The script fetches the current time using the `time` module.
- It calculates the angles for the hour, minute, and second hands using trigonometric functions.
- The hands are redrawn every second to update their positions.
